## Overview

This repository brings together solutions, reference implementations and teaching material for computational methods applied to physics. The collection covers numerical experiments, simulation workflows and problem-solving with Python/Jupyter, including differential equations, stochastic systems, mechanics and epidemiological models.

## What You Will Find

- Numerical modeling and simulation exercises
- SIR/SIRS/SEIR epidemiological models
- Binomial and Poisson distribution studies
- Ordinary differential equation solutions
- Projectile and mass-spring simulations
- Random-number and gas-system experiments
- Coursework solutions and supporting material

## Engineering Value

Although created in an academic/teaching context, this repository documents practical experience translating mathematical models into executable computational experiments — a foundation used later in data products, scientific applications and solution architecture.

## Tech Stack

`Python` · `Jupyter Notebook` · `Numerical Methods` · `Scientific Computing` · `Simulation`

## Repository Guide

The repository is organized by assignments, exercises and computational topics. Start from the folders associated with the model or numerical method you want to explore; notebooks contain the executable analyses and visual outputs.
